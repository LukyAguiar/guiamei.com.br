# MEI & Simples Nacional — Guia Completo

Projeto Next.js 15 com uma única página explicando como pagar o DAS-MEI e cumprir as obrigações do Simples Nacional.

## Como rodar

```bash
# 1. Instale as dependências
npm install

# 2. Rode em desenvolvimento
npm run dev

# 3. Acesse
# http://localhost:3000
```

## Build para produção

```bash
npm run build
npm start
```

## Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Google Fonts: DM Serif Display + DM Sans
